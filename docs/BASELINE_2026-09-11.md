Values such as `Restricted Access` bypassed the API's `Restricted` comparison. Queries now project the stable code, the lyrics API checks registered and restricted access against the current principal, and its responses are marked no-store because visibility varies by user.

Application caching remains on query-service data and is invalidated after admin writes. Those mutation queries, including bulk variants and backing Entity rows, now use explicit tracking.
